## Code reference

summary: No code table sizes a generator; two sections apply to the parts around it. {.open}

- **Sizing rules:** the two starting-watts rules are industry conventions. Retail guides mostly add every running load plus the largest starting load (the conservative rule, the default here); some manufacturers let the largest starting load replace its own running watts.
- **445.13:** conductors from the generator terminals to the first overcurrent device need an ampacity of at least 115% of the generator's nameplate current.
- **Table 430.7(B):** a motor's locked-rotor kVA per horsepower from its code letter, for working out starting current when the nameplate doesn't give starting watts.
