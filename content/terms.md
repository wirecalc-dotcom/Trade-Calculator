## Free calculators

The calculators and charts are free and provided as-is. They do the arithmetic of the formulas and code tables named on each page, using values from the National Electrical Code (NEC) as cited there. They don't replace the code book, a design by a qualified person, or the judgment of the authority having jurisdiction (AHJ).

{{ahj}} Local amendments, the edition your jurisdiction has adopted, equipment listings and installation instructions can all change the answer. Check the result before you rely on it, and size conductors, raceways and equipment to the requirements that apply to your installation.

We work to keep every formula and table value right, and each calculator is tested against published worked examples. We can still make mistakes, and we aren't liable for losses that come from using a result without checking it.
