## Code reference

summary: These are the power formulas themselves; no code table is involved. {.open}

- **Three-phase:** uses the line-to-line voltage and √3. A load on 480 V three-phase draws about 58% of the current the same watts would draw on 480 V single-phase.
- **Power factor:** real power (watts) is volts × amps × power factor. Nameplates on motors often give amps and kVA rather than watts.
