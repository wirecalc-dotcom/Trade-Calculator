# Plan (from project handoff, Oct 30 2026)

## Why
Electrical won Screen 26: ~170K/mo cheap calculator searches (weighted low bid ~$0.06), paid side "electrician software" bids $227, ~300K/mo chart lookups (pro behavior). Money comes from the audience (survey data, sponsors, consent-based leads, small display ads), never from charging electricians.

## MVP calculators (order = cheap search volume)
1. Voltage drop — 50K/mo, $0.04
2. Conduit fill — 50K (+ conduit fill chart 50K), $0.12
3. Ohm's law — 50K, $0.02
4. Wire size / wire gauge — 5K each (+ charts 50K each)
5. Generator size — 5K
6. Amps ↔ watts — 5K
Plus a free ampacity chart page (50K, $0.35).

## Each calculator page
Calculator → result → formula + code reference → worked example → (later) 5-question survey on the result screen. Plain "powered by" embed version of each calculator.

## Phase 4 decision rule ($50–100 ads, floor bids, pro terms only)
Measure cost per visit, survey completion, emails, return visits within 14 days (pause ads a week).
- Pass: ≥ 15% return without ads AND cost per completed survey ≤ $2.
- Fail: < 5% return → stop.
The analytics/click tracking copied from dnsmailcheck must be able to report exactly these numbers.

## Lessons carried in
- dnsmailcheck: built paid features with no demand signal; ~$130, 0 paid. Don't repeat.
- UpsetSale: cheap clicks ≠ buyers.
